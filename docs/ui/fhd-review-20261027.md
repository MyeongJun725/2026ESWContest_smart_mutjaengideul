# Full HD UI 검토본 · 2026-10-27

사용자 요청: 1920×1080, 기존 아이보리/화이트/버건디 팔레트 유지, 카메라 바로 아래 큰
수어 결과, 간결한 도움/응답 문구, 새 UI에서 가려진 재난 API 기록 복구.
LG 로고·제공 SDK·라이브러리를 새로 포함하지 않았다.

## 변경

- 홈 카메라 하단에 결과 전용 strip을 붙였다. 결과 40px, 대기 32px이며 연결이 끊긴 뒤
  남은 값에는 “최근 인식 결과”를 표시한다. 홈에서는 별도 중앙 수어 popup을 중복 표시하지 않는다.
- “수어로 이야기해요” → “수어 인식”, “수어를 기다리고 있어요” → “입력 대기”.
  홈 “도움이 필요해요” → “도움 요청”, 응답 “괜찮아요” → “괜찮습니다”.
  도움 문안·대상 선택·반응 선택의 문구를 간결하게 정리했다. 실제 신고/연락 미전송 고지는 유지했다.
- `재난·알림` 카드에서 API 원문·지역·발행 시각을 최근 대화와 독립적으로 표시한다.
  설정 누락·조회 중·빈 기록·실패를 구별하고, 조회 실패 시 이전 문자를 유지한다.
  기록이 없을 때 카드를 누르면 연결 설정 또는 재조회로 연결된다.
- 재난 API가 최신순/오래된순 어느 쪽이든 매 조회에서 첫 페이지와 마지막 페이지를 확인한다
  (최대 2회). 이전 마지막 페이지 캐시가 새 첫 페이지 알림을 놓치던 경로를 수정했다.
  URL의 기존 필터는 보존하고, 임의 API 오류 메시지/URL에 포함된 인증정보를 로그에 남기지 않는다.
- 식별번호가 없는 응답은 참고 내용으로 표시하되 경보를 생성하지 않는다. 기존 식별·지역·
  발행 시각에 따른 경보 판단을 약화하지 않았다. 재난 문자 표시가 화재경보음/YAMNet 인식을 뜻하지 않는다.

사용자가 상단 카드 높이/전체 배치 비율은 기존 배치를 유지하도록 선택해 해당 비율은 바꾸지 않았다.
현재 Pi5의 개인 설정, 실제 API key·네트워크·설치본과 일치하는지는 미확인이다.
이전 UI와 앱의 설정 저장 경로가 다르다면 기존 설정을 보존하고 연결 설정에서 API 주소/key를 확인한다.
실제 인증정보를 채팅·Git·ZIP에 넣지 않는다.

## ZIP과 설치 경계

검토용 `code.zip`은 Git 추적 소스 전체다. SDK·빌드 산출물·인증정보·개인 설정·기존 실행본을 포함하지 않는다.
`ui-source.zip`은 현재 앱 디렉터리의 소스/runner/검사/자산만 담은 작은 검토본이다.
`ui-preview.zip`은 PC용 web 빌드다. 압축을 풀고 그 폴더에서 다음 명령으로 화면을 열 수 있다:

```sh
python -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8766`을 연다. 미리보기에서 연결 설정 저장·장치 기능을 시험할 필요는 없다.
이 ZIP들은 ATLAS 설치 패키지(IPK)가 아니다. 기존 Pi5가 사용하는 ATLAS SDK/audio plugin과
빌드 절차로 설치 패키지를 만들어야 한다. 기존 앱 ID는 `com.atlas.app.safehub_scenario_pr7`이다.
현재 cloud에서는 ATLAS 패키징·설치·서비스 제어·실제 재난 API·스피커를 시험하지 않았다.
Pi5 설치 전 기존 IPK/설정과 실행 상태를 보존하고 검토한 패키지로만 적용한다.

화면 원본: `SW/safehub_scenario`. 재현 도구: `tool/prepare_host_tests.py`, `tool/run_ui_preview.py`.
수집 로그/화면/ZIP은 `/workspace/.cloud-setup/fhd-ui-review-20261027/`에 별도로 보관한다.
