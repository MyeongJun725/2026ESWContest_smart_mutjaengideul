# 홈 UI 두 항목 검토본

사용자가 기존 화면을 유지하고 **맨 아래 도움 요청 버튼**과 **카메라 바로 아래 수어 결과**만
수정하도록 범위를 좁혔다. 기존 넓은 검토본 e77d118은 Git 이력과 별도 bundle/ZIP에 보존했다.

기준 UI는 4e4d0d1(#11 develop 통합본 + #12 도움 수어 TTS)이다.

- 홈 버튼 문구를 “도움 요청 / 수어·터치로 선택”으로 정리한다. 원래 위치·색상·크기·기능은 유지한다.
- 카메라 바로 아래 결과 strip을 붙인다. 인식 결과 40px, 기존 대기 문구 32px로 표시한다.
  수어 대화 버튼과 연결 끊김 시 최근 결과 표시를 유지한다.
- 상단·최근 알림·재난 API·자막·설정·도움 응답 화면·배치·팔레트는 기준 UI와 동일하다.
  이전 넓은 검토본의 재난 API/카드/다른 문구 수정은 이 검토본에서 제외했다.

미리보기는 Flutter로 렌더링한 PC 화면이며 실제 카메라·API·장치 시험이 아니다.
ZIP은 소스/PC web 미리보기이며 ATLAS 설치 패키지가 아니다. Pi5 적용 전에 팀 SDK로
패키징하고 기존 실행본·개인 설정을 보존한다. 장치 설치나 서비스 제어는 수행하지 않았다.

검사: Flutter 259 pass / 0 fail / 1 실제 fastText opt-in skip. 분석 error 0 / warning 0 /
info 102, `--no-fatal-infos` exit 0. 제품 web release 빌드 성공. 원래 재난 서비스·상태 카드·
응답 화면·배치·테마·연결 설정 파일은 기준 커밋과 byte 일치를 확인했다.
