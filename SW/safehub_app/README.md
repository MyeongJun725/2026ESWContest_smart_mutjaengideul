# 이전 SafeHub UI 소스

현재 통합 후보의 UI·runner·자산·테스트는 **[../safehub_scenario](../safehub_scenario/README.md)** 에 있습니다.
새 기능 개발·빌드·호스트 검사는 그 경로를 사용하세요. 이 폴더를 새 UI와 함께 실행하지 않습니다.

이 폴더는 최종 삭제 범위를 결정하기 전의 이전 소스로 보존하고 있습니다.
현재 UI는 이 폴더의 `lib`, runner, 플러그인, 폰트·이미지를 가져다 쓰지 않습니다.
Dart package와 실행 파일의 `safehub_app`이라는 이름은 현재 UI에도 쓰이며 폴더 선택과 다릅니다.

삭제 판단과 검증 경계는 [정리 기록](../../docs/integration/ui-consolidation-20261027.md)을 참고하세요.
실제 장치에 설치된 앱/사용자 데이터의 제거·교체를 지시하는 문서가 아닙니다.
