# 이벤트 팝업과 화면 시연

최신 `SW/safehub_scenario`의 홈·수어 대화 화면 위에 사건별 팝업을 표시합니다.
기존 배경 UI, 글꼴, 이미지, MQTT 규격과 장치 명령 경로를 사용합니다.

## 화면 실행

Python 3와 Flutter SDK가 설치된 PC에서 저장소 루트 기준으로 실행합니다.
처음 실행할 때 Flutter 패키지와 웹 빌드 도구를 다운로드할 수 있습니다.

```sh
python SW/safehub_scenario/tool/run_ui_preview.py
```

Flutter가 PATH에 없다면 실행 파일 경로를 지정합니다.

```sh
python SW/safehub_scenario/tool/run_ui_preview.py --flutter-path "C:/flutter/bin/flutter.bat"
```

브라우저가 자동으로 열립니다. 기본 주소는 `http://127.0.0.1:8766/`이며,
이미 사용 중이면 `--port 8877`처럼 다른 포트를 지정합니다. 종료는 Ctrl+C입니다.
소스만 검사하려면 `--check-only`, 브라우저를 자동으로 열지 않으려면 `--no-browser`를 사용합니다.

도우미는 기존 앱의 `lib`와 `assets`를 임시 호스트로 복사합니다.
그 복사본에서만 ATLAS 전용 플러그인 등록과 브라우저의 로컬 설정 파일 접근을 제외합니다.
저장소의 `pubspec.yaml`, 실제 장비 설정과 원본 앱은 바꾸지 않습니다.
SDK, 빌드 파일, 이미지 복사본을 저장소에 추가할 필요가 없습니다.

## 세 가지 시나리오

체험 모드의 화면 하단에 빠른 시연 버튼이 표시됩니다.

| 버튼 | 팝업 |
| --- | --- |
| ① 방송 화재 | 방송 원문, 대피 안내, LED·베드셰이커 전달 상태 |
| ② 재난 알림 | 재난 종류, 지역·발행 시각과 원문, 원문의 안전 행동 안내 |
| ③ 보호자 도움 | 기존 카메라 영상과 터치 버튼 동시 표시, 반응 여부, 119 요청 문안 |

보호자 도움 창에는 수어 시작 버튼이 없습니다. 기존 수어 인식 결과가
`SituationService.receiveSign`으로 들어오면 도움·구조·쓰러짐 계열 라벨에 대해
‘119에 신고할까요?’를 자동으로 표시합니다. 반복 결과는 중복 창을 만들지 않습니다.
확인하면 해당 사건의 주소·원문·선택한 반응 여부·수어 응답으로 문안을 준비합니다.

연결된 카메라는 기존 영상 스트림을 그대로 사용합니다. 장비 없는 브라우저 시연은
연결 대기를 표시합니다. 수어 결과 수신 후의 UI만 시험하려면 다음 주소를 사용합니다.

- `http://127.0.0.1:8766/?signDemo=help`
- `http://127.0.0.1:8766/?signDemo=collapse`

이 주소는 3초 뒤 **시연 입력**을 주입합니다. 실제 카메라 인식 결과가 아닙니다.
일반 주소에는 자동 수어 입력이 없습니다. 기존 분류기의 ‘구조’는 연결할 수 있지만,
‘쓰러짐’ 인식에는 별도 모델 학습·배포가 필요합니다.

모든 새 팝업과 신고 확인·신고 내용 창은 우측 상단 X로 닫을 수 있습니다.
기존 ‘SafeHub로 돌아가기’도 유지합니다. ‘신고하기’는 현재 **시연 요청 안내**를
표시하며 실제 119 문자·영상통화·접수·출동 처리를 수행하지 않습니다.

## 실기와 검사

ATLAS에서는 기존 앱 설치·연결 절차를 사용합니다. 하단 시연 버튼과 URL 수어 주입은
`APP_LOCAL_PREVIEW=true`일 때만 활성화됩니다. 실제 모드의 사건 수신과
`_sendScenarioSignal`은 기존 MQTT 경로를 유지하며, 명령 제출과 장치 동작 확인을 구분합니다.

LLM 청취·추론, 실제 재난 API 수신, Pi 카메라·CSI·LED·베드셰이커 성능은
이 화면 시연의 검증 범위가 아닙니다. UI 팝업은 활성 사건을 직접 확인하므로
홈 외 다른 탭에서도 표시됩니다. 화면 확인·X 닫기는 위험 해제를 뜻하지 않습니다.

표준 Flutter 호스트 또는 기존 ATLAS 개발 환경에서:

```sh
flutter test test/scenario_event_overlay_test.dart
```

방송·재난·터치·수어 입력, 카메라 동시 표시, 중복 방지, 사건 종료, X 닫기와
신고 버튼 등 신규 동작 검사 10개를 포함합니다. 기존 전체 테스트의 문제를
모두 수정한 변경은 아닙니다.
