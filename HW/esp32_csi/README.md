# ESP32-C6 CSI 소스 보존

현재 CSI 수신기에 필요한 C6 송수신 펌웨어 소스는 옛 독립 데스크톱 앱과 분리해 보존합니다.
`SOURCE_PROVENANCE.json`의 고정 SHA에서 소스·PlatformIO 설정·패키징 도구와 라이선스를
바이트 그대로 옮겼습니다. 원래 경로는 `WiFi-CSI-Sensing/firmware-c6`입니다.
과거 UI·설치 프로그램이나 빌드된 bin 파일은 현재 제품 소스에 함께 넣지 않았습니다.

이는 새 펌웨어의 빌드·실물 호환·플래시 결과가 아닙니다. 실제 보드에 설치된 펌웨어와의
일치 여부는 미확인입니다. `platformio.ini`의 ESP-IDF/칩/role 설정을 먼저 확인하세요.
`package_firmware.py`는 기존 성공 빌드의 파일을 병합하는 개발 도구이며 보드에 접속하지 않습니다.
보드 플래시는 별도 사용자 지시가 필요합니다. `.pio`·`bin` 산출물은 커밋하지 않습니다.
